# FableTest — Architecture Map

Companion to `docs/PROGRESS.md`. Namespaces mirror folders under
`Assets/_Game/Scripts/` (asmdef `Game.Runtime`; editor tools in `_Game/Editor`, asmdef
`Game.Editor`).

## Iron rules

1. **Solo = host** (loopback, port 0). No singleplayer branches anywhere.
2. **Server authority by default**; owner authority only for the player body and held
   physics items (NetworkTransform AuthorityMode.Owner + ownership transfer).
3. **UI is authored in prefabs** (generated once by Game/Setup builders); C# is behavior
   only. Runtime code never constructs UI hierarchies (the old project died of this).
4. **No reflection wiring, no GameObject.Find in hot paths.** Serialized refs + a few
   `static Instance` singletons with `[RuntimeInitializeOnLoadMethod(SubsystemRegistration)]`
   resets.
5. **Anything time-driven that must survive late join** is a pure function of
   `NetworkManager.ServerTime.Time` with its schedule in NetworkVariables — never a local
   state machine (the old metro desync).
6. One canonical data folder: `_Game/Resources/Items` (+ future `Resources/Quests`) so ids
   resolve identically on every peer.

## System map (file → responsibility)

### Core (`Game.Core`)
- `GameConfig.cs` — GameConfig + GameConfigNet (INetworkSerializable), difficulty/visibility.
- `SessionContext.cs` — static menu→game handoff: Config, SelectedSaveSlot, IsContinue.
- `SettingsService.cs` — SettingsData JSON @ persistentDataPath/settings.json; applies
  quality/res/vsync/fps/mip + per-player FOV/AA/sensitivity/invert + binding overrides.
  PSX internal height + dither read live by the post process.
- `GameEventBus.cs` — string event bus (quest flags).

### Net (`Game.Net`)
- `NetworkBootstrap.cs` — UGS init + anon auth (Boot scene), Burst kill-switch.
- `NetworkSessionManager.cs` — THE session entry: StartSessionAsync(config) for
  solo/private/public host; JoinByLobbyAsync/JoinByCodeAsync; LeaveAsync; connection
  approval (payload = protocolVersion + authPlayerId + name) → ServerPlayerRegistry.
- `LobbyController.cs` / `RelayConnector.cs` — UGS lobby (heartbeat, join code in data,
  private lobbies) / relay (dtls).
- `ServerPlayerRegistry.cs` — server map clientId→authPlayerId (saves/quests/admin key).
- `NetworkGameState.cs` — scene object (World): replicates GameConfigNet.
- `NetworkPlayer.cs` — player prefab root: owner-gates camera/input/listener/interaction,
  pitch NV for remote head aim, spawn-point warp, audio listener suppression.
  Static `Local` + `OnLocalPlayerReady`.
- `WorldItemNetworkSync.cs` — pickup (server validate→targeted grant RPC→despawn) +
  carry ownership transfer; quantity NV for late joiners.
- `WorldItemManager.cs` — scene object (World): server spawns items (initial scatter,
  drops via ServerRpc, admin gives).

### Player / Interaction
- `Player/FirstPersonController.cs` — Input System FPS (crouch/sprint/coyote/invert),
  `AddExternalMove` hook for moving platforms, sensitivity/speed multipliers.
- `Player/PlayerStats.cs` — server-write Health NV (medical hook).
- `Interaction/InteractionSystem.cs` + `IInteractable` — raycast + prompt event.
- `Interaction/WorldItem.cs` — interactable item; `Interaction/PhysicsPickup.cs` —
  spring-damper carry (Grab hold / Throw / scroll distance), heavy-item slowdown,
  kinematic-skip while ownership transfers.

### Inventory (`Game.Inventory`)
- `ItemData.cs` (SO, Resources/Items) + `ItemDatabase.cs` (id lookup).
- `InventoryGrid.cs` — spatial grid model (rotate/stack/auto-place). `PlayerInventory.cs`
  — 8x5 grid + cash + save DTO (GetState/ApplyState).

### UI (`Game.UI`) — all layout generated by `_Game/Editor/*Builder.cs`
- `MenuScreenManager` + screens: Title, SaveSlots, GameSetup (unified SP/MP creation),
  LobbyBrowser, Settings (Graphics/Audio/Controls tabs + rebinding via RebindRow).
- `PauseMenu` (Esc), `HUDController` (crosshair, interact prompt, health bar, clock),
  `QuestToastUI` (top-right accept/complete popups; `Show(string)` is reusable for any
  notice), `ConsoleUI` (backquote admin console).
- `TabMenuUI` (Tab: Inventory/Quests/Map), `Inventory/InventoryGridUI` + `ItemWidgetUI` +
  `ItemPreviewStage` (offscreen HDRP camera → RT; hover=show, click=spin+info),
  `QuestLogUI`, `MapView` (top-down ortho camera → RT + per-player arrow icons; camera
  renders only while the tab is open; world XZ maps linearly to the image, icon Z rotation
  = -player yaw).

### Rendering (`Game.Rendering`)
- `PSXPostProcess.cs` + `Resources/Shaders/PSXPost.shader` — downsample→quantize+dither→
  upscale (After Post Process). Registered by `Editor/PSXSetup.cs` (reflection).
  `Shaders/PSXVertex.hlsl` — Custom Function code for the future PSX Lit graph.

### Save (`Game.Save`)
- `SaveSystem.cs` — Slot{N}/meta.json today; Phase 12 adds world/quests/players payloads.
  HOST-ONLY disk IO; clients restored via authPlayerId.

### World (`Game.World`)
- `PlayerSpawnPoint.cs`. (TimeManager/WeatherManager/platforms land in Phases 8–9.)

## Scene contents

- **Boot**: NetworkBootstrap, NetworkSession (NetworkSessionManager+LobbyController;
  networkManagerPrefab ref; gameplayScene="World").
- **MainMenu**: MenuCamera, MainMenuUI prefab instance, EventSystem (InputSystemUIInputModule).
- **World**: Sun (40k lux), Sky and Fog Volume (template profile + PSX override + motion
  blur off), Ground, TestCubes, PlayerSpawn, NetworkGameState, WorldItemManager (scatter),
  WorldUI prefab instance (HUD/TabMenu/Pause/Settings), EventSystem.

## Prefabs

`_Game/Prefabs/`: NetworkManager (UTP, approval ON, scene mgmt ON, player prefab),
NetworkPlayer (CC+FPC+Stats+Interaction+PhysicsPickup+PlayerInventory+NetworkPlayer+
owner-auth NetworkTransform; camera excludes ItemPreview layer), Items/{4 items},
ItemPreviewStage. `_Game/UI/`: MainMenuUI, WorldUI, SettingsPanel, SlotRow, LobbyRow,
RebindRow, ItemWidget. NGO prefab registration is automatic via
`Assets/DefaultNetworkPrefabs.asset`.
